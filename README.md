## 📌 Projects

### 💳 [FinOps Autopilot](https://github.com/mantu-kumar05/finops-autopilot)

An agentic financial reconciliation platform that matches payments against settlements, classifies exceptions by severity (Critical/High/Medium), flags anomalies with an ML model, and routes them through an automated resolution agent.

**Demonstrates:** designing a multi-stage backend pipeline (reconciliation → exception detection → ML scoring → resolution), working with realistic financial data structures (payments, settlements, mismatches) using synthetic data, and integrating ML into a live operational workflow.

`FastAPI` `PostgreSQL` `SQLAlchemy` `scikit-learn` `React`

### 💵 [PayFlow — Payment Dashboard](https://github.com/mantu-kumar05/payflow)

A payment operations dashboard UI — revenue overview, transaction search/filtering by status, and customer management — structured the way real fintech product dashboards are.

**Demonstrates:** frontend architecture for data-heavy interfaces, responsive design, and thinking about a product from the user's (ops team's) point of view, not just the code.

`Next.js` `React` `TypeScript` `Tailwind CSS`

### 📊 [Finance Analytics System](https://github.com/mantu-kumar05/Finance-Analytics-System)

A personal finance analytics backend with JWT-authenticated REST APIs that computes per-user income, expense and savings summaries, paired with a Streamlit dashboard for managing transactions and viewing expense categories.

**Demonstrates:** authentication and per-user data isolation (JWT / OAuth2), designing a REST API (register, login, transactions, analytics), automated API testing with Pytest, and connecting a Streamlit client to a FastAPI backend.

`Python` `FastAPI` `SQLite` `Pandas` `Streamlit` `Pytest`

### 📝 [ComplaintPortal](https://github.com/mantu-kumar05/ComplaintPortal)

A Java web application where users register, log in and file complaints, and admins view, filter, resolve and delete them through a role-based dashboard.

**Demonstrates:** server-side web development with Servlets and JSP, session-based authentication with role-based access control, JDBC with prepared statements, and relational schema design in MySQL.

`Java` `JSP` `Servlets` `JDBC` `MySQL` `Apache Tomcat`
